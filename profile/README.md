# K4rta Lab 🃏

> Open-source community TCG — colecciona, intercambia y batalla con cartas diseñadas por la comunidad.

K4rta Lab es un juego de cartas digital donde cualquiera puede contribuir diseños.
La comunidad vota qué cartas se añaden al juego, y cada temporada trae nuevos packs temáticos.

---

## Repositorios

| Repo | Descripción |
|---|---|
| [k4rta-core](../k4rta-core) | Backend principal — Spring Boot 3, Java 21 |
