# K4rta Lab 🃏

> Full-stack TCG built from scratch as a portfolio project

K4rta Lab es un proyecto personal donde aplico y documento decisiones de arquitectura reales: modelado de dominio, autenticación con JWT, migraciones versionadas, un sistema de trading con integridad transaccional, y un cliente web construido con TanStack Query y un design system propio sobre MUI.

---

## Repositorios

| Repo | Descripción |
|---|---|
| [k4rta-core](https://github.com/K4rta-Lab/k4rta-core) | Backend — Spring Boot 3, Java 21, PostgreSQL, Flyway, JWT |
| [k4rta-generator](https://github.com/K4rta-Lab/k4rta-generator) | Generador de sobres — Rust, RNG determinista y auditable |
| [k4rta-web](https://github.com/K4rta-Lab/k4rta-web) | Cliente web — React + TypeScript, TanStack Query, MUI |
| k4rta-android | Cliente Android — Kotlin + Jetpack Compose *(planeado)* |
